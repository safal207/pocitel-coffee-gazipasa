Тела ответов измерены через Resource Timing и Navigation Timing через 900 мс после события load. Для каждого сравнения использованы отдельные URL ресурсов, без повторного использования кэша. Мобильный замер сделан до исправления клавиатурного перехода. Оно меняет только атрибут в HTML и селектор обработчика. В обоих профилях браузер выбрал один вариант главного фото для первого экрана.

Один проход на профиль. Время до load составило 117 → 73 мс на мобильном профиле и 79 → 98 мс на настольном. Эти значения зависят от стенда и не подтверждают ускорение по времени на реальных устройствах. LCP внутри тестового iframe не получен. В двух парах измерений зарегистрирован CLS 0. Ограничение сети и полевые Core Web Vitals не измерялись.

Главное фото подготовлено под видимую область с прежней композицией. Подключены подходящие по ширине версии и ранняя загрузка. Иконки историй получают отдельные миниатюры. Подготовка JPEG загружается при открытии окна отправки фото.

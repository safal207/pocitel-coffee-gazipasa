# Sharing, category navigation and light surfaces

The share sheet now previews the selected product and prepares its exact image as a JPEG before the final user tap. Native file sharing includes the JPEG, localized product name, serving format and product link. Unsupported or rejected native sharing leaves a photo download and copy-link fallback; cancellation keeps the sheet usable. Preview/access query parameters are excluded from shared links. Closing invalidates pending image work and revokes object URLs.

Category, saved-only and service-mode changes scroll to the start of the filtered feed under the measured sticky controls. Menu/combination links use the same target. Typing in search does not trigger that scroll. Reduced-motion preference is respected.

The page canvas, main content and hero/menu sections explicitly paint the light brand background. `color-scheme: only light` remains declared, and asset URLs are versioned. Forced-dark behavior on the user's actual mobile browser is still unverified.

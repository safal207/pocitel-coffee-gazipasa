# Focaccia cutaway

The smoked-turkey focaccia and the lunch pairing featuring it include a comparison slider in their menu viewer. The illustration shows focaccia bread, smoked turkey, tomato, arugula, and avocado sauce, matching the menu description. Both views are AI-generated illustrations and are labelled accordingly.

The slider is a native range control with localized instructions in Turkish, English, and Russian. At 390 px and 320 px widths, the viewer was checked for layout; pointer dragging, keyboard navigation, the English and Russian labels, and adding the focaccia to the order were checked in the browser. The automated Node test suite provides the existing order and menu regression coverage.

# Poçitel moment collections

Four curated collections filter real menu items for a slow morning, a bite, a takeaway walk and a sweet moment. Selecting a collection is optional, and the menu's category and service controls can return to the broader menu.

The focaccia builder lets guests save individual combinations, including serving format, milk and syrup, in the current browser. Saved combinations can be reopened or removed. No personal profile or external service is needed.

Another pairing cycles through valid combinations without changing selected milk, syrup or serving format. An optional budget applies to the suggestion's actual total; if no other combination fits, the current selection remains and an explanation is shown. No selection is added to the cart until the guest acts.

Validation: 22 Node tests passed, including curated product availability, saved configurations, budget, unsupported extras and existing checkout behavior. Mobile browser checks covered 390×844 Russian and 320×568 English views, light and dark themes, filtering, saving and reloading a customized pairing, no matching budget, and adding a suggested pairing to the cart. An order is a local draft to show the cafe staff.
